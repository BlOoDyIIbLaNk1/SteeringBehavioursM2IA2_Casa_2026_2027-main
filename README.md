- Dossier : [`12-SIMvoiture`](12-SIMvoiture/).
- [Ouvrir la simulation en ligne](https://bloodyiiblank1.github.io/SteeringBehavioursM2IA2_Casa_2026_2027-main/12-SIMvoiture/).

Les deux liens ouvrent directement leur projet, sans page d’accueil commune.
